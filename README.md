# Adventure-Works-Sales-Dashboard-Power-BI

# Project Overview

This project is an interactive Power BI dashboard built using the Adventure Works dataset.

The dashboard provides insights into:
- Sales performance
- Product categories
- Regional analysis
- Customer behavior
- Profit trends

# Data Model Overview

The dashboard follows a Star Schema Data Model, which is considered a best practice in Power BI for building scalable and high-performance dashboards.

The model consists of:

1 Fact Table
Multiple Dimension Tables

The central fact table stores transactional sales data, while the dimension tables provide descriptive information such as customer details, product hierarchy, date information, and sales territory.

This structure improves:

- Query performance
- Filter propagation
- Dashboard responsiveness
- Scalability for future enhancements
